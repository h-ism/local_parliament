件名：会議録データベースの研究目的での利用について（お願い）

北海道議会事務局議事課 御担当者様

突然のご連絡失礼いたします。{所属・職名}の{氏名}と申します。
{大学・研究機関名}にて、地方議会の会議録を対象とした{計量テキスト分析／政策過程}
の研究を行っております。

このたび、貴議会の「会議録データベース」
（https://pref-hokkaido.gijiroku.com/voices/）に公開されている会議録を、
研究用のテキストコーパスとして利用させていただきたく、ご相談いたします。

【利用の目的と範囲】
- 目的：学術研究（{研究課題名}）における分析資料としての利用
- 対象：本会議及び委員会の会議録（当面は令和7年分、将来的には過年度分も）
- 利用形態：発言単位のテキストデータとして蓄積し、統計的な分析に使用します。
  会議録本文そのものを再配布する予定はありません。公表物では出典を
  「北海道議会会議録」として明記いたします。

【ご依頼】
1. 会議録のテキストデータを一括してご提供いただくことは可能でしょうか。
   （形式は問いません。CSV、テキスト、PDF等、ご都合のよいもので結構です。）
2. 一括提供が難しい場合、当方のプログラムから会議録データベースを
   自動で取得することの可否についてご教示ください。
   同システムの robots.txt では `/voices/cgi/` が Disallow と指定されており、
   会議録の一覧・本文はこの配下にあるため、当方では取得を見合わせております。
   研究目的での取得をお認めいただける場合、遵守すべき条件（アクセス間隔、
   実施時間帯、事前のご連絡等）もあわせてお示しいただけますと幸いです。
3. 会議録データベースは貴議会とは別のドメインで運用されているようですので、
   システムの運用事業者様へのご確認が必要な場合は、その旨お知らせください。

【サーバへの負荷について】
自動取得をお認めいただける場合、以下の配慮を行います。
- 1リクエストにつき{2}秒以上の間隔を空け、並列アクセスは行いません
- 取得済みのページはすべて手元に保存し、同じページを再取得しません
- User-Agent に研究用である旨と当方の連絡先を明記します
  （例：`prefectural-transcripts/0.1 (academic research crawler; contact: {メールアドレス})`）
- 業務時間帯を避けた実施や、実施日時の事前連絡など、ご指示に従います
- 支障が生じた場合は直ちに停止しますので、下記までご連絡ください

## 返答が来たら

  読み込みスクリプトを書く。CSV 出力はすでにある。

  記録したうえで、`docs/hokkaido.md` の draft config の TODO を実ページで
  埋める。`PT_MIN_INTERVAL` は指定された値以上に設定する。
- 不可 → 速報 PDF 経由（`docs/hokkaido.md` の選択肢3）か、他県への切り替えを検討。
