宛先: 栃木県議会事務局 {担当課・担当者名 — 2026-09-24 の回答者に合わせること}
差出: **共同研究者B** — 栃木への照会はこの方の名義。**滋賀・石川の
共同研究者Aとは別人**なので、署名も User-Agent の連絡先も取り違えないこと。

2026-09-24 の回答で「メールに記載した方法であればスクレイピング可」とされ、
あわせて**実行のタイミングを事前に知らせてほしい**との指示があった。これはその
連絡であって、依頼ではない。

**送る前に3つ。**

0. **差出人を間違えない。** 栃木の窓口が知っているのは共同研究者Bであって、
   このプロジェクトの `PT_CONTACT` でも共同研究者Aでもない。`sites/tochigi.toml` の
   `[contact]` にも共同研究者Bのアドレスを入れる（**未取得**）。
1. **日付を決めてから送る。** 本文の `{開始日}`〜`{終了日}` と、
   `sites/tochigi.toml` の `[notice]` の `last_sent` / `covers_until` は
   **同じ日付**にすること。ずれると、通知した覚えのない期間に走るか、通知した
   期間に走れないかのどちらかになる。
2. **下見も「実行」に含めて書く。** 40ページ程度でも先方のサーバへのアクセスに
   変わりはなく、「下見は連絡の対象外」と勝手に決める理由がない。
3. **規模は下見のあとでないと言えない。** 栃木の archive の件数は未確認なので、
   本文では「下見のうえ改めてお知らせします」とし、二段構えにしてある。

送ったら `[notice]` に記録する。記録するまで `pt scrape tochigi` は1件も取得
しない（`Notice` が停止させる）。

```toml
[contact]
address = "{共同研究者Bのメールアドレス — 未取得}"
note = "照会は共同研究者Bが行い、2026-09-24 に許可を得た"

[notice]
who = "栃木県議会事務局 {担当課}"
last_sent = "{送信日}"
covers_until = "{終了日}"
what = "{開始日}〜{終了日}の20時〜翌7時。初回は数十ページの下見、以降は会議録本文。1件2秒以上・直列。"
```
