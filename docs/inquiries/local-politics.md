## なぜこの1通が最優先なのか

**これは許可の依頼ではなく、二重取得を避けるための照会である。** 他の30通とは
性格が違う。

先方は都道府県議会の会議録を **全47議会・2011年4月〜2019年3月**（年度区切り。
「2011–2014」「2015–2019」という表記だが暦年ではない）について既に整備しており、
423団体・約1億3,400万文・約80GB と報告されている。

当方の収集方針は「取得できる限りの全期間」であるから、この期間は**除外対象ではなく
むしろ確実に欲しい範囲**である。そして先方が既に持っている以上、同じものを47議会分
クロールし直すのは、当方の手間としても、各議会のサーバへの負荷としても、正当化
できない。

現時点の収集実績も、この境界を前提に組み立てられている:

| 県 | 収集済み | 意図的に空けた範囲 |
| --- | --- | --- |
| 和歌山 | 1989-02-27 .. 2025-12-19（907件） | 2011-04 .. 2019-03 |
| 愛媛 | 2019-05-15 .. 2026-03-09（201件） | 同上（平成3年〜2011年は未収集） |
| 静岡 | 2025年のみ（113件） | — |

**つまり、この照会の結果が出るまで、和歌山と愛媛には意図的な穴が空いたままになる。**

## 聞くべきことの要点

1. **一括提供の可否と条件** — 本題。
2. **収録範囲の正確な確認** — 2011年4月〜2019年3月という理解で正しいか。本会議と
   委員会の別。当方の記録は二次情報に基づくので、一次情報で確かめる。
3. **2019年4月以降の継続予定** — ここが効く。継続しているなら、当方が今クロール
   している範囲まで重複する可能性がある。**尋ねなければ分からない。**
4. **整形の粒度** — 発言単位か、話者・役職が分離されているか。当方は愛媛で
   「氏名と役職が区切りなしに連結された標識」に当たり、分離を断念して `speaker` に
   全文字列を入れ `role` を空にしている。先方が既に解いているなら、その設計は
   参考になる。
5. **こちらから提供できるもの** — 当方が収集した範囲（とくに和歌山 1989–2011 の
   673件）は、先方の収録範囲より古い。一方的に受け取るのではなく、差し出せるものは
   差し出す。
