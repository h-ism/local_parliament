**取得の可否について、2026-08-27 に前提が変わった。** かつては「robots.txt が
`/tenant/` を Allow しているので取得自体は許容されている」と書いていたが、誤り
だった。公開画面は Allow だが、データを返す API は `/dnp/search/` にあり、
`/tenant/` の外なので `Disallow: /` の対象。**これは許可の依頼である。**
