研究用のテキストコーパスとして利用させていただきたく、ご相談いたします。

【ご依頼】
1. 会議録のテキストデータを一括してご提供いただくことは可能でしょうか。
   （形式は問いません。CSV、テキスト、PDF等、ご都合のよいもので結構です。）
2. 一括提供が難しい場合、当方のプログラムから同システムのデータを取得することの
   可否と、その方法についてご教示ください。同システムの robots.txt は `/tenant/`
   配下を Allow としており、取得自体は許容されているものと理解しておりますが、
   画面が JavaScript で構成されているため、データの取得先が分からず着手できて
   おりません（取得先を記述したスクリプトは robots.txt で Disallow とされている
   ディレクトリにあるため、参照を控えております）。
3. 同システムは外部事業者により運用されているものと拝察いたします。事業者様へ
   直接照会すべき事項であれば、窓口をお教えいただけますでしょうか。
