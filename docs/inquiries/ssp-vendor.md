宛先: **NTT アドバンステクノロジ株式会社**（`config.js` の著作権表示より）。
部署・窓口は未確認。以前ここに「ページ内に DNP のロゴ画像あり」と書いていたのは
読み違いで、**DNP は製品名 Discuss Net Premium の略**（名前空間も `dnp.*`）。
窓口が分からない場合は、利用している議会の事務局経由で照会するのが早い。

**2026-08-27 に前提が変わった。** かつてここには「robots.txt が `/tenant/` を
Allow しているので取得の可否は問題にならない」と書いていた。誤りだった。
公開画面は確かに Allow だが、データを返す API は `/dnp/search/` にあり、これは
`/tenant/` の外なので `Disallow: /` に該当する。**取得は許可されていない。**

したがってこれは「やり方を教えてほしい」ではなく、**許可またはデータ提供の依頼**
である。あわせて、大阪府議会のページに明記されている再利用条件（下記）は robots
とは別に残るため、それも含めて尋ねる。

このテナント方式には18の県議会（宮城・秋田・山形・福島・埼玉・神奈川・新潟・岐阜・
大阪・奈良・岡山・山口・徳島・高知・長崎・熊本・大分・沖縄）が載っているため、
1件の回答で18県分の見通しが立つ。
